Assignment question 3

No smartphones, LLMs exist: attendance for 1000 people across 100 locations

Core idea

Use voice-first and shared-device attendance: each site has a landline/basic phone, biometric terminal, or supervisor kiosk. Employees mark attendance with employee ID plus voice confirmation or biometric scan. An LLM reconciles exceptions, detects anomalies, and calls supervisors/employees for clarification.

Daily workflow

  1. Employee checks in from the location terminal or calls the IVR number.
  2. System verifies employee ID, location code, shift, and optional voice biometric phrase.
  3. LLM flags missing, duplicate, late, or wrong-location records.
  4. Voice AI calls supervisors for unresolved exceptions before payroll cutoff.
  5. HR sees a dashboard by location, shift, attendance status, and unresolved cases.

Controls

Location-specific phone lines or terminal IDs, rotating spoken passphrases, supervisor approval, CCTV/register fallback for low-connectivity sites, audit logs, and exception sampling prevent proxy attendance.
